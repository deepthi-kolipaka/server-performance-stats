# Server Performance Stats

A Bash script to analyze basic Linux server performance statistics.

## Features

- Total CPU Usage
- Total Memory Usage
- Total Disk Usage
- Top 5 Processes by CPU Usage
- Top 5 Processes by Memory Usage
- OS Version
- Uptime
- Load Average
- Logged-in Users

## Usage

Make the script executable:

```bash
chmod +x server-stats.sh
```

Run the script:

```bash
./server-stats.sh
```
